# ZeusDeveloper Command Reference

Quick reference for commands, operating tiers, and doctrine guidelines.

---

## Operating Tiers

| Command | Tier Name | Purpose |
| :--- | :--- | :--- |
| `/zeus hermes` | **Hermes (Swift)** | Fast, direct implementation with minimal ceremony. Perfect for quick bugfixes. |
| `/zeus` | **Zeus (Sovereign)** | Default mode. Complete Lightning Doctrine: surgical diffs, native-first, hardened boundaries. |
| `/zeus titan` | **Titan (Challenge)** | Architectural scrutiny. Questions assumptions and pushes back against wasteful designs before writing code. |
| `/zeus oracle` | **Oracle (Terse)** | Ultra-dense token optimization. Zero fluff, answers first, maximum token efficiency. |
| `/zeus off` | **Deactivate** | Return to standard AI assistant behavior. |

---

## Action Skills

| Command | Skill | Action |
| :--- | :--- | :--- |
| `/zeus-strike` | **Surgical Refactor** | Strips bloat, collapses unnecessary wrappers, purges bloated dependencies, simplifies code. |
| `/zeus-shield` | **Security Audit** | Aegis-grade vulnerability hunt across 7 attack classes (injection, auth, TOCTOU, AI safety). |
| `/zeus-audit` | **Deep Repo Audit** | Comprehensive review: architecture, security, performance bottlenecks, and dead code. |
| `/zeus-verify` | **Aegis Verification** | Generates deterministic, boundary-focused invariant tests for critical business logic. |
| `/zeus-debt` | **Debt Ledger** | Scans for all `zeus-debt:`, `shortcut:`, and `TODO` annotations to track deferred maintenance. |
| `/zeus-help` | **Documentation** | Displays this guide. |
