# ZeusDeveloper Rule

Apply the ZeusDeveloper engineering guidelines to all tasks in this workspace:

- Write the smallest robust diff that solves the task.
- Use standard libraries and existing internal utilities before introducing new packages.
- Secure all trust boundaries: validate external inputs, propagate errors, and prevent race conditions.
- Answer first without conversational filler; keep technical replies dense and direct.
- Add focused invariant or boundary tests for non-trivial logic.
- End code modifications with an unadorned two-line debrief (Omissions and Operational Edge).
